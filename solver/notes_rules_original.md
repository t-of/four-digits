# 2027 パズルのルールまとめ

## 1. 問題

4つの数字 a, b, c, d(例:2, 0, 2, 7)を**この順番のまま**、各1回ずつ使って、1〜100 のすべての整数を式で作る。

## 2. 使える記号

| 記号 | 内容 | 備考 |
|---|---|---|
| `+` `−` `×` `÷` | 四則演算 | 引き算は2項のみ(単独の − とは別扱い) |
| `( )` | 括弧 | |
| 連結 | 隣り合う数字をつなげる(20、27、202 など) | 先頭が 0 の連結は不可(02 など) |
| 小数点 | 数字と数字の間に置く(2.0、0.1 など) | 先頭の `.2` は不可 |
| 単独の `−` | 負の数(−2 など) | |
| `√` | 平方根 | 答えが分数・整数になる場合のみ(√9=3、√(1/4)=1/2) |
| `^` | 冪乗 | 指数は整数のみ |
| `!` `!!` `!!!` | 階乗・二重階乗・三重階乗 | 0! = 1 |
| N重階乗 `n!⁽ᴺ⁾` | n×(n−N)×(n−2N)×… | N=1,2,3,… すべて含む家族として扱う |
| 部分階乗 `!n` | 完全順列の個数 | !0=1, !1=0, !2=1, !3=2, !4=9, !5=44 |

### 記法のメモ
- `n!⁽ᴺ⁾` は、n から N ずつ引きながら 1 より大きい間を掛ける。例:`20!⁽¹⁸⁾ = 20×2 = 40`、`7!⁽⁵⁾ = 7×2 = 14`、`7!!! = 7×4×1 = 28`
- `2^0^27` は右から計算する。`2^(0^27) = 1`
- 階乗の引数が式のときは括弧で包む。`(2+0)!`
- ガンマ関数(整数の引数のみ)も試したが、結果は変わらなかった。小数引数(Γ(1/2) = √π など)は無理数になるため未対応。
- 循環小数は検討したが、プログラムには未実装。

## 3. 探索の設定と限界(全探索で使った値)

| 項目 | 値 |
|---|---|
| 途中の値の上限 | 絶対値 10³⁶ 未満、分母 10¹⁸ 以下(128ビット整数) |
| 階乗の対象になる数 | 通常の階乗は 33 まで(上限内)。N重階乗は 3〜100(広げた探索では〜1000) |
| 単項演算を重ねる回数 | 6回以上(3回では不足した。6〜30回で結果は同じ) |
| 冪乗の指数 | −200〜200(記号数最小の探索では −64〜64) |
| 部分階乗の対象 | 0〜33 |

上限を変えると結果が変わる可能性がある。

## 4. 結果

### 4-1. 2027 は 1〜100 すべて作れる
上記の記号をすべて使えば、1〜100 すべて作れる(全式は別途の一覧を参照)。

### 4-2. 0000〜9999 の全10,000通り
- 記号を少しずつ広げて調べた結果、**10,000通りすべてで 1〜100 が作れる**。
- 最後まで残ったのは 0000 と 0001。
  - 0001 は小数点(0.1 など)で解決。
  - 0000 は 9, 27, 81 が残り、部分階乗で解決:
    - 9 = `!(0!+0!+0!+0!)`
    - 27 = `(!(0!+0!+0!+0!))!⁽⁶⁾`
    - 81 = `((!(0!+0!+0!+0!))!⁽⁶⁾)!⁽²⁴⁾`

### 4-3. 記号の「種類数」を最小にした場合(2027)
- 括弧と数字は常に使えるものとし、記号の種類を最少にする。
- **2種類で足りる:`−`(引き算)と N重階乗**(! も !! も N重階乗の仲間として1種類と数える)。
- 1種類・0種類では作れない。
- 階乗の仲間(`!`、`!!`、`!!!`、N≧4)を別々の記号と数えると、最少は **3種類**。
  - 例:{`−`、連結、N重階乗(N≧4)}、{`−`、N重階乗(N≧4)、部分階乗}
- 2種類で確認できたのは「−とN重階乗」の組だけ。他の2種類の組が不可能かは、N重階乗の対象を 100 までに絞った探索のため断定できない。

### 4-4. 記号の「個数」を最小にした場合(2027)
**数え方**

| 項目 | 数え方 |
|---|---|
| 括弧 | 開きと閉じのペアで1個 |
| 連結(20 など) | 0個 |
| 小数点 | 1個 |
| 演算記号 | `+ − × ÷ ^ √`、単独の `−` は各1個 |
| 階乗類 | `!`、`!!`、`!!!`、`n!⁽ᴺ⁾`、部分階乗 `!n` は、どれも1個 |

**括弧が必要になる規則(式を印刷するとき)**
- 優先順位は、足し引き < 掛け割り < 単独のマイナス < 冪乗 < 階乗 < かたまり(数・括弧・√)。
- 優先順位が低い式を高い演算の対象にするときは括弧が必要。
- 2項演算の右側に単独のマイナスが来るときは括弧で包む。
- 階乗・√・部分階乗の対象は、数か括弧で包んだ式のみ。

**結果:1〜100すべて、最大4個**

| 個数 | 1個 | 2個 | 3個 | 4個 |
|---|---|---|---|---|
| 数の個数 | 1 | 24 | 59 | 16 |

- 1個の数:47 = `20+27`
- 4個必要な数:20, 21, 22, 41, 42, 44, 58, 60, 64, 78, 80, 84, 90, 96, 98, 100

この個数は、階乗の対象を 100 までなどの制限の範囲内での最小。

## 5. 検算の方法
- 全探索はC++(128ビット整数)で実行。
- 出てきた式は別のPythonプログラムで文字列から再パースして、次の3点を確認した。
  1. 計算結果が目標の数と一致する
  2. 式の中の数字(2,0,2,7)が順番どおり1回ずつ出る
  3. 記号の個数が探索結果と一致する(個数最小の探索のみ)
