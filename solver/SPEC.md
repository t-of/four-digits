# 式の仕様（ゲームと最小記号数の計算で共通）

ゲーム（このリポジトリの `src/expr.js`）と最小記号数の計算（`solver/src/`）は、この仕様で一致させる。直すときは両方を合わせる。
元のルールは `notes_rules_original.md`（オーナーが 2027 で調べたもの）。

## 問題

4 桁 `abcd`（0000〜9999）と目標 t（1〜100）。数字 a,b,c,d を **この順番のまま各 1 回ずつ** 使い、値がちょうど t になる式を作る。

## 数（リテラル）

- 隣り合う数字をつなげてよい（連結、記号 0 個）。例 `20`、`202`、`2027`。
- 2 桁以上のかたまりの先頭が 0 は不可（`02` は不可。`0` 単独は可）。
- 小数点: かたまりの中の数字と数字の間に 1 つまで置ける（記号 1 個）。`2.0`、`0.2`、`20.27` は可。`.2`・`2.` は不可。小数点の前が 2 桁以上なら先頭 0 は不可（`02.1` 不可、`0.21` 可）。
- 値はすべて正確な有理数で扱う。

## 演算と記号の個数

| 記号 | 書き方 | 個数 | 条件 |
|---|---|---|---|
| 足す・引く・掛ける・割る | `a+b` `a−b` `a×b` `a÷b` | 1 | 0 で割れない |
| 冪乗 | `a^b` | 1 | 指数は整数。0 の 0 以下乗は不可。右結合（`2^0^2 = 2^(0^2)`） |
| 単独のマイナス | `−a` | 1 | |
| 平方根 | `√a` | 1 | 結果が有理数のときだけ（`√9`、`√(1/4)`）。a ≥ 0 |
| N 重階乗 | `n!`（N=1）、`n!!`（N=2）、`n!!!`（N=3）、`n!⁽ᴺ⁾`（N≥1 任意） | 1（N によらない） | n は 0 以上の整数。n×(n−N)×(n−2N)×… を正の間だけ掛ける。0!⁽ᴺ⁾ = 1 |
| 部分階乗 | `!n` | 1 | n は 0 以上の整数。!0=1, !1=0, !n=(n−1)(!(n−1)+!(n−2)) |
| 括弧 | `( … )` | 開きと閉じの組で 1 | |
| 連結 | | 0 | |
| 小数点 | `.` | 1 | |

## 優先順位と括弧

低い順: 足し引き < 掛け割り < 単独のマイナス < 冪乗 < 階乗（後置） < かたまり（数・括弧・√・部分階乗）

- 階乗・√・部分階乗の **対象は、数か括弧で包んだ式だけ**。`(3!)!`、`√(√16)`、`!(2+2)` のように括弧が要る。`3!!` は二重階乗の意味になる。
- 冪乗の底は階乗以上（`3!^2`・`√4^2` は可、`(−2)^2`・`(2^3)^2` は括弧が要る）。指数は冪乗以上（右結合）。指数に単独のマイナスを置くときは括弧（`2^(−1)`）。
- **部分階乗を冪乗の底にするときは括弧が要る**（`!2^7` は不可、`(!2)^7` は可。`!2^7` が `!(2^7)` と読み違えられやすいため。2026-11-06 オーナー）。指数には置ける（`2^!3`）。
- 単独のマイナスは式の先頭か `(` の直後だけ（`−2^2 = −(2^2) = −4`、`−−2` は不可）。
- 足し算の右側の足し引き、掛け算の右側の掛け割りは括弧なしで書ける（`a+(b−c)` は `a+b−c` と同じ）。ただし右側が単独のマイナスで始まるときは括弧が要る。
- 2 項演算の右側に単独のマイナスが来るときは括弧（`3×(−2)`、`3−(−2)`）。
- 引き算の右側が足し引きなら括弧、割り算の右側が掛け割りなら括弧。左側は同じ高さなら括弧なし。
- 掛け算の省略（`2(3)`）はなし。

ゲームでは、プレイヤーが打った括弧はすべて数える（要らない括弧も 1 個）。最小記号数の計算では、要る括弧だけを数える。

## 文字での書き方（例の式のファイルとゲームの解析で共通）

`+` `−`（U+2212。2 項も単独も同じ字）`×` `÷` `^` `√` `(` `)` `.`、階乗は `!` `!!` `!!!`、N 重階乗の一般形は `!{N}`（例 `20!{18}`、`7!{3}` は `7!!!` と同じ）。
部分階乗は数か括弧の前の `!`（`!4`、`!(0!+0!)`）。空白なし。ゲームの表示では `!{N}` を `!⁽ᴺ⁾` と見せてよい。

## 星（ゲーム）

その問題の最小記号数を m、プレイヤーの式の記号数を k とする。

- k ≤ m → ★3
- m+1 ≤ k ≤ m+2 → ★2
- それより多い → ★1

## 最小記号数の表（計算 → ゲーム）

`results/min.bin`（ゲームには `data/min.bin` として写す）: 1,000,000 バイト。
添え字 = s×100 + (t−1)（s は 4 桁の数 0〜9999、t は 1〜100）、値 = 最小記号数（0〜254）。255 は「探索の範囲で見つからない」。

この最小は、探索の範囲（階乗の対象の上限など、`README.md` に書く）の中での最小。プレイヤーが m より少ない式を見つけることはあり得る（そのときも ★3）。
